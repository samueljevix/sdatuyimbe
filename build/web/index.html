How to install SDA Tuyimbe Book (.msix)

If you see "Publisher not verified", follow one of the safe options below.

Option 1: Enable Windows Developer Mode

Turning on Developer Mode allows Windows to install local testing packages (.msix) without certificate restrictions.

  1. Press the Windows Key on your keyboard and search for Developer settings.
  2. Under Developer Mode, turn the toggle to On.
  3. Locate the downloaded sda_tuyimbe_book.msix file on your computer.
  4. Double-click it, and click the Install button to complete installation.
Tip: This is the quickest option and doesn't require modifying certificate stores manually.

Option 2: Manually Trust the Self-Signed Certificate

If you don't want to turn on Developer Mode, you can trust the application's certificate so Windows allows installation.

  1. Right-click the downloaded sda_tuyimbe_book.msix file and select Properties.
  2. Go to the Digital Signatures tab, select the signature listed, and click Details.
  3. Click View Certificate, then click Install Certificate...
  4. Select Local Machine and click Next. (Approve the administrator popup if requested.)
  5. Choose Place all certificates in the following store, click Browse, select Trusted Root Certification Authorities, and click OK.
  6. Click Next, then click Finish.
  7. Double-click the .msix package — the Install button will now be active.

FAQ

Why does Windows show "Publisher not verified"?

This happens when the app isn't code-signed by a recognized publisher. Click "More info" and then "Run anyway" to install securely.

Can I use this on a projector?

Yes. The app is built for large-screen presentation and projector display during worship services.

Does it support Luganda and English hymns?

Yes. Every hymn includes both Luganda and English text to support bilingual congregations.

Is the app really offline?

Yes. Once installed, the app works without internet because the hymns, audio files, and notation are packaged locally on your device.

What languages are supported?

The app includes both Luganda (Tuyimbe) and English hymn texts, making it easier to worship and teach in either language.

Will the installer work on Windows 10 and 11?

Yes. The package is designed for Windows 10 and 11, and the guide includes the simplest trusted-install steps for both versions.
